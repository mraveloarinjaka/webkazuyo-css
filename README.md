# webkazuyo-css

Generated Tailwind stylesheet (`output.css`) for
[webkazuyo](https://github.com/mraveloarinjaka/webkazuyo).

The file on the default branch is the latest released stylesheet and can be
fetched without authentication:

```sh
curl -L -o output.css \
  https://raw.githubusercontent.com/mraveloarinjaka/webkazuyo-css/main/output.css
```

Each production release also tags this repository with the matching release tag
(e.g. `v1.2.3`), so a pinned copy is available at:

```sh
curl -L -o output.css \
  https://raw.githubusercontent.com/mraveloarinjaka/webkazuyo-css/v1.2.3/output.css
```

Do not edit `output.css` by hand: it is regenerated by the release workflow of
`webkazuyo`.
